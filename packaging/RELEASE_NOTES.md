# iPhone GPS v0.1.0

首个发行版。本次提供 Windows x64 独立程序包，Linux 使用源码安装。

- 固定定位、连续坐标更新，支持命名地点保存与调用。
- GCJ-02 输入自动转换为 WGS84。
- 开发者模式入口显示；Linux 通道快捷启动。
- Windows 独立程序支持 Apple 设备组件安装及通道管理。

- **Windows x64**：下载 `iphone-gps-windows-x64.zip`，完整解压后在程序目录打开 PowerShell 使用。
- **Linux**：下载源码，按 README 安装。Windows ZIP 不能在 Linux 直接运行。

使用方法：[README](https://github.com/OMORI-GOHAN/iPhone-gps/blob/v0.1.0/README.md)。
